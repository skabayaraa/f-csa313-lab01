## 1. Хийсэн ажлын хураангуй
Энэхүү лабораторийн ажлын дагуу Microsoft Playwright автоматжуулалтын хэрэгслийг ашиглан SauceDemo (https://www.saucedemo.com) веб систем дээр функционал тестүүдийг бичиж гүйцэтгэсэн. Үүнд стандартын дагуу амжилттай нэвтрэх (системийн logout үйлдлээр төгсөх), амжилтгүй нэвтрэх (negative test) болон нэвтэрсний дараа бараа сагсанд нэмэх зэрэг үндсэн функциональ тестүүдийг хэрэгжүүлж, үр дүнг шалгасан.

## 2. XPath-аас яагаад зайлсхийсэн бэ?
XPath нь HTML DOM модны бүтэц болон замын дарааллаас хатуу хамааралтай байдаг тул веб хуудасны загвар эсвэл классын нэр бага зэрэг өөрчлөгдөхөд л тест шууд амжилтгүй болж унах талтай. Тиймээс хэрэглэгчийн харах өнцөг болон харилцан үйлдэлд суурилсан Playwright-ийн орчин үеийн locator-ууд болох `getByRole`, `getByPlaceholder`, `getByText` аргуудыг ашигласан нь кодыг илүү хялбар, засварлахад амар болгож байсан.

## 3. Codegen болон өөрийн бичсэн кодын ялгаа
Playwright Codegen хэрэгслийг ашиглахад хэрэглэгчийн хийсэн бүх үйлдлийг нэг бүрчлэн автоматаар бичдэг бөгөөд зарим тохиолдолд хэрэггүй код үүсгэх хандлагатай байдаг. Харин өөрөө гараар логиктойгоор бичихэд шаардлагатай тестийн алхмуудыг тодорхой болгож, гарах утгуудыг (Assertions) зорилготойгоор оновчтой байдлаар төлөвлөх боломжтой байдгаараа ялгаатай.

## 4. Playwright болон Selenium хоёрын харьцуулалт (Ажиглалт)
Selenium бол веб автоматжуулалтын анхдагч суурь хэрэгсэл хэдий ч хөтөч тус бүрийн driver-уудыг тус тусад нь татаж тохируулах, элемент бэлэн болохыг хүлээхийн тулд Explicit wait-ийг олон дахин гараар бичих шаардлага гардаг нь хөгжүүлэлтийг удаашруулдаг. Харин Microsoft-ын хөгжүүлсэн Playwright нь элемент веб хуудсанд бүрэн ачаалагдахыг автоматаар хүлээдэг (Auto-wait) өндөр хурдтай функцтэй бөгөөд шаардлагатай хөтчүүдийг нэг командаар бүрэн суулгадаг. Мөн Trace viewer болон HTML report зэрэг суурилуулсан хэрэгслүүд нь алдааг олж debug хийхэд илүү ойр болж байгаа нь Selenium-ээс илүү орчин үеийн, хурдан бөгөөд найдвартай шийдэл болно.
